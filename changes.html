Implemented

Binary-safe Huffman File Archiver

This update changes the project from a text-only compressor into a lossless archiver for any file type.

What changed

  • All input and output now use binary mode, preventing corruption of PDFs, images, videos, presentations, and arbitrary data.
  • The compressor now handles all 256 byte values, instead of only 128 ASCII characters.
  • A new versioned HUF1 archive format stores the original filename, extension, original size, compression method, and Huffman frequency table.
  • Decompression restores the exact original bytes and preserves the original file extension.
  • The Huffman tree has deterministic tie-breaking, so an archive can always rebuild the same tree while restoring.
  • Archives now use a stored mode when Huffman metadata would make the file larger.
  • The command-line decoder accepts an optional output path and otherwise uses the archived filename without overwriting an existing file.
  • The desktop interface now suggests the archived filename automatically when restoring a file.
  • Error messages report damaged archives, invalid headers, incomplete data, and file-access problems clearly.
  • Older archives created by the original text-only format are not compatible with the new HUF1 format; keep the earlier executable if you need to restore them.

Archive layout

PartPurpose
HUF1 + versionIdentifies this archive format safely.
Original filenameRestores extensions such as .pdf, .png, .mp4, and .pptx.
Original sizeLets the decoder know exactly when restoration is complete.
MethodChooses Huffman coding only when it wins; otherwise raw bytes are stored safely.
Frequency table / payloadContains enough information to recreate compressed data exactly.

How to use it

  • Build: g++ -std=c++17 -O2 encode.cpp huffman.cpp -o encode.exe and g++ -std=c++17 -O2 decode.cpp huffman.cpp -o decode.exe
  • Archive: encode.exe input.pdf output.huf
  • Restore: decode.exe output.huf restored.pdf
  • Or run huffman_gui.py and use the two buttons.

Important: JPEG/PNG images, MP4 videos, PDFs, and Office files are often already compressed. This update can archive them safely, but it may not make them smaller. Meaningful size reduction for those formats needs optional, format-specific tools and may be lossy.
